LogPulse

Distributed log aggregation & observability

Service Health

Live via a beacon protocol: each service refreshes a Redis key with a short expiry every 3s. If a service goes silent, Redis deletes the key on its own — no manual failure detection needed.

Mutual Exclusion — Archive Lock

Two independent workers periodically compete to run a maintenance task. Redis's atomic SET ... NX guarantees only one ever holds the lock at a time.

Trace Lookup

Ordered by Lamport logical clock, not wall-clock time. If a request's clock jumps by more than 1, it means that service's event was causally triggered by another service's event elsewhere.
Enter a trace ID to reconstruct its path across services, ordered by Lamport clock.

Live Logs

Streamed by 4 independent agents through gRPC, buffered in a Redis Stream, and durably stored by 2 competing workers.
